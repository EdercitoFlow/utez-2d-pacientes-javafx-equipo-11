👥 Integrantes

📌 Descripción
Este proyecto consiste en una aplicación de escritorio desarrollada en JavaFX para la gestión de pacientes de un consultorio.

El sistema permite realizar operaciones CRUD (Crear, Leer, Actualizar y Eliminar), además de guardar la información en un archivo local para mantener los datos entre ejecuciones.

⚙️ Tecnologías utilizadas
Java
JavaFX
FXML
Programación Orientada a Objetos (POO)
🧩 Funcionalidades
Registro de pacientes
Visualización en tabla
Edición de datos
Eliminación lógica (Activo/Inactivo)
Persistencia en archivo (.txt o .csv)
Validaciones de datos
🖥️ Interfaz
Pantalla principal con TableView
Formulario de registro de pacientes
